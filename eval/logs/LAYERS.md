# แต่ละชั้นของ harness กันอะไรได้

จำลองให้โมเดลทำผิดแบบที่ชั้นนั้นมีไว้กัน (สคริปต์แทนโมเดลจริง) แล้วรันเทิร์นเดียวกันตอนเปิดกับปิดชั้นนั้น

| ชั้น | โมเดลทำผิดแบบไหน | เปิดชั้นนี้ | ปิดชั้นนี้ |
|---|---|---|---|
| gate (contract pre-tool-use) | สั่ง delete_invoice ทันทีโดยผู้ใช้ยังไม่ยืนยัน | บิลยังอยู่ ได้ preview รอยืนยัน | บิลถูกลบ |
| check_args | ส่ง argument ที่ tool ไม่มี (shop แทน vendor) | tool ตอบ error พร้อมรายชื่อ argument ที่ใช้ได้ | tool เงียบ ได้ยอดรวมทุกร้าน 329 บาท (จริง 184) |
| ROUTE_IMAGE | ได้รูปแล้วตอบเลย ไม่เรียก analyze_receipt | อ่านใบเสร็จแล้ว ได้ draft รอยืนยัน | ไม่ได้อ่านใบเสร็จ ไม่มี draft |
| _parse ขอใหม่ | ตอบเป็นข้อความว่าจะบันทึก แต่ไม่เรียก tool | ขอ JSON ใหม่ แล้วบันทึกจริง | ตอบว่า "ผมจะบันทึกให้" แต่ไม่ได้บันทึก |
| ontology | ส่งหมวดเป็นคำที่คนพูด (ค่าน้ำมัน) | ได้ยอด 210 บาท (จริง 210) | ได้ยอด 0 บาท (จริง 210) |
| ตรวจคำตอบ (contract หลังตอบ) | แต่งยอดที่ไม่มีในผลจาก tool (5,400 แทน 329) | ขอใหม่ ผู้ใช้ได้ "ใช้ไปทั้งหมด 329 บาทครับ" | ผู้ใช้ได้ "เดือนนี้ใช้ไปทั้งหมด 5,400 บาทครับ" |
